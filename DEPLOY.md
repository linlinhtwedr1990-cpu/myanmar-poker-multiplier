# Deploy V10.3

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files inside this folder (including `index.html`, `v102.html`, and `src/`).
3. In GitHub: **Settings → Pages → Deploy from a branch**.
4. Select the main branch and `/ (root)`.
5. Wait for GitHub Pages to publish the site.
6. Open the HTTPS Pages URL.
7. Create a room and copy the invite link.

Players only need the published web link; they do not need the ZIP.
