# Myanmar Poker Multiplier V10.4 — GitHub Pages

## 1. Create a GitHub repository
Create a new repository named:

    myanmar-poker-multiplier

For the easiest setup, make it Public.

## 2. Upload the game files
Upload the CONTENTS of this folder to the repository root.
The file `index.html` must be in the repository root.

Do not upload the ZIP itself as the website.

## 3. Enable GitHub Pages
In GitHub:

Settings → Pages

Under "Build and deployment":
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

Wait for GitHub to publish the site.

## 4. Open your game
GitHub will provide a URL similar to:

https://YOUR-USERNAME.github.io/myanmar-poker-multiplier/

## 5. Share it
Send that URL to your players. They can open it on Android, iPhone,
Windows, Mac, or another modern browser.

## Important multiplayer note
GitHub Pages is static hosting. It serves HTML/CSS/JavaScript but does
not provide a persistent real-time multiplayer server.

The V10.4 package prepares the website for public hosting. A separate
free/low-cost real-time networking/signaling service is still required
for players on different devices to exchange live game-state updates.

Do NOT enable Firebase Blaze billing just to publish this website.
