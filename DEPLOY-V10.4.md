# Myanmar Poker Multiplier V10.4 — GitHub Pages

## Upload correctly
Upload the **contents of this folder** directly into the repository ROOT.

The root must directly contain:
- `index.html`
- `v104.html`
- `src/`
- `tests/`

Do NOT place this whole folder inside another folder.

## Recommended Pages setting
GitHub → Settings → Pages

- Source: **Deploy from a branch**
- Branch: `main`
- Folder: `/ (root)`
- Save

Then open:
`https://linlinhtwed1990-cpu.github.io/myanmar-poker-multiplier/`
