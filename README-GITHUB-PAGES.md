# Myanmar Poker Multiplier V10.3 — GitHub Pages deployment

This package is prepared for a repository root deployed with GitHub Pages.

## Upload
Upload/replace the files in the repository root, preserving the `src/` folder.

The important entry point is:

- `index.html`

You can also open:

- `v102.html`

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Then open:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

For this project:

`https://linlinhtwed1990-cpu.github.io/myanmar-poker-multiplier/`

## Multiplayer note
The lobby uses PeerJS/WebRTC for the prototype. No Firebase billing is required for this prototype.
